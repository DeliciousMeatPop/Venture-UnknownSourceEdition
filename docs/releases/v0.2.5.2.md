## Venture: Unknown Source Edition 0.2.5.2

A fork of [Venture](https://github.com/Villagers654/Venture) by Villagers654, built on upstream **0.2.5.1**. It adds one thing: an opt-in **dev identity**, so development builds and apps from outside the Meta store can run without a Meta account. Everything else is upstream Venture, with his credit and his work front and centre in the README.

### What's new in this fork

**Dev identity (per app, off by default)**
- An app with dev identity starts as a local "Developer" user. No Meta account is read or contacted, platform calls (user, leaderboards, achievements, in-app purchase reads) get local answers, and the ownership check is not performed.
- Apps you don't turn it on for are unchanged. Store games keep Meta sign-in, ownership checks and purchases exactly as upstream.
- **Turn it on:** press **Play** on a game whose package name has a `dev` segment (for example `com.dev.studio.game`) and the launcher asks once. For any other app, open its **more** menu and choose **Use dev identity**.
- **From a terminal:** `venture-cli play GAME --dev-identity` (saved), `--no-dev-identity` to turn it off.
- A **DEV IDENTITY** badge shows on the game's page while it's on, and the logs say so.

**Also**
- The update check follows **this fork's** releases, not upstream's.
- New Unknown Source Edition logo and Windows icon.
- README credits upstream and carries a dev identity disclaimer.
- Includes upstream's 0.2.5.1 fix (the shipped Java runtime now has the crypto it needs for HTTPS).

### Read this first
- Dev identity is **new and lightly tested**. Expect rough edges, and please report them.
- It is for **developers and for software not sold through the Meta store**. It is not a way around ownership or licence checks for store games, and we don't support that use. See the [disclaimer](https://github.com/DeliciousMeatPop/Venture-UnknownSourceEdition#dev-identity-disclaimer).
- Without a Meta account, dev apps get canned platform answers: no friends, no multiplayer services, empty leaderboards and purchase history.

### Downloads
- **Windows:** `Venture-windows64-setup.exe` (installer) or `Venture-windows64.zip` (portable).
- **Linux:** the packages attached below (`.tar.gz`, AppImage and others).
